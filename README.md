# AI Receptionist / Missed-Call Recovery SaaS

Business + technical blueprint docs for a standalone AI receptionist / missed-call
recovery SaaS idea — an early-stage concept, not yet built.

## Docs

- [`AI_RECEPTIONIST_SAAS_BLUEPRINT.md`](./AI_RECEPTIONIST_SAAS_BLUEPRINT.md) —
  the core business + technical blueprint: market validation, competitive
  landscape, MVP scope and recommended stack, unit economics/pricing,
  legal/compliance (TCPA, HIPAA, recording consent), go-to-market, and a
  phased roadmap.
- [`AI_RECEPTIONIST_VOICE_TO_WEB_HANDOFF_BLUEPRINT.md`](./AI_RECEPTIONIST_VOICE_TO_WEB_HANDOFF_BLUEPRINT.md) —
  a deeper, opinionated look at one specific feature: the mid-call SMS→web
  handoff (visual-IVR precedent, funnel realism, UX design, technical
  architecture, competitive positioning, unit economics, revised MVP scope).

## Status

Research/planning stage. Phase 0 (customer validation via cold-calling
target businesses) has not yet been run — treat the numbers in these docs
as directional until real conversations happen.
